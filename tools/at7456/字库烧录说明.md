# AT7456E 字库烧录工具

本目录由 RK3506 SDK 管理，包含独立的 Linux spidev 字库烧录程序和
Betaflight 标准 MCM 字库，不依赖 PX4 构建系统。

## 编译

在本目录执行：

    make

默认使用 arm-linux-gnueabihf-gcc，为 ARM32 Cortex-A7 生成静态程序：

    build/at7456e_font

如需指定工具链：

    make CROSS_COMPILE=/path/to/toolchain/bin/arm-linux-gnueabihf-

## 上传

    scp build/at7456e_font betaflight.mcm root@192.168.123.100:/tmp/

## 烧录

烧录前必须解除武装、拆除螺旋桨、保证供电稳定，并停止 PX4 OSD 驱动：

    atxxxx stop

建议先只烧录空白字符 0x20，确认满屏字符问题消失：

    /tmp/at7456e_font --yes write-char /tmp/betaflight.mcm 0x20

完整烧录并逐字符读回校验：

    /tmp/at7456e_font --yes write /tmp/betaflight.mcm

完成后恢复 OSD：

    atxxxx start

Betaflight 字库与当前 PX4 的大部分符号编码相同，但并非完全一致。例如
0x70 在 Betaflight 字库中是速度图标，而当前 PX4 驱动将其作为飞行时间
图标。完整烧录前应确认符号映射。
